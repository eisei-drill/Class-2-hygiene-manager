# 二種衛生管理者ドリル

第二種衛生管理者試験の問題演習Webアプリ（PWA）です。スマホのホーム画面に追加でき、一度開けばオフラインでも動きます。

## 収録内容
- 400問（関係法令136・労働衛生131・労働生理133）
- 種類：過去問頻出型（公表試験問題で繰り返し問われる論点を再構成）207問／オリジナル193問
- 各問題に頻出度★1〜5、選択肢ごとの解説、全体の解説、覚え方のポイント、根拠法令
- 法令基準日：2026年10月1日（令和3年12月・令和4年の事務所衛生基準規則改正、令和6年の雇入れ時教育の省略規定廃止、令和7年の熱中症対策義務化、令和8年4月施行の高年齢者の労働災害防止の努力義務を反映）

## 機能
- 模擬試験：本試験と同じ30問（各科目10問）・3時間・合否判定（各科目40%以上かつ合計60%以上）
- 復習：間違えた問題を自動で復習リストへ。2回続けて正解すると外れる
- 条件演習：科目・分野・頻出度・種類・未回答/間違い/ブックマークで絞り込み
- 問題一覧とキーワード検索、ブックマーク、文字サイズ・ダークモード、学習データの引き継ぎ
- 合格可能性：科目ごとの直近40問の正答率から本試験の得点を推定（各科目15問以上で判定）
- 試験日の設定：残り日数と、試験日までに未正解・復習待ちを一巡できる1日の目標問題数を表示
- 苦手分野の分析：分野ごとの正答率を低い順に表示し、そのまま演習
- 数字の暗記カード：出題されやすい数字71枚を一問一答で
- 解答後に「これが正解」「あなたの解答」を表示し、○×の意味と「誤っているものを選ぶ問題」かどうかを案内
- 問題の誤り報告（GitHubのIssueに下書きを作成、または報告文をコピー）
- ホーム画面への追加の案内、プライバシーポリシー・利用規約・問題の作成方針のページ
- 模擬試験の中断・再開、保存データの検証

## ファイル
| ファイル | 内容 |
|---|---|
| index.html | アプリ本体（問題データ内蔵の1ファイル） |
| manifest.webmanifest / sw.js / icons/ | ホーム画面追加・オフライン動作用 |
| questions.json | 問題データ（編集用の元データ） |
| 問題一覧_確認用.csv | 校正用の一覧（Excelで開けます） |

## 公開方法
1. このフォルダをそのまま静的ホスティング（GitHub Pages、Netlify、Cloudflare Pages など）にアップロードします。HTTPSで公開するとオフライン対応が有効になります。
2. App Store / Google Play で配布する場合は、Capacitor などでこのWebアプリをラップしてストア申請します。

## 運営者情報・利用状況の集計の設定
index.html の先頭近くにある `CONFIG` で設定します。
- `operator`：プライバシーポリシーと利用規約に表示する運営者名
- `reportUrl`：問題の誤り報告の送り先（初期値はこのリポジトリのIssue）
- `analyticsScript` / `analyticsCode`：利用状況の集計（例：GoatCounter）。空のままなら何も送信しません。設定するとプライバシーポリシーの記載も自動で切り替わります。

## 公開前に確認してほしいこと
- 問題と解説は作成時点の法令にもとづいています。法改正があった場合は該当問題を修正してください（特にストレスチェックの50人未満事業場への義務化は令和10年4月施行予定）。
- 「過去問頻出型」は本試験の問題文をそのまま転載したものではありません。公表試験問題を原文のまま収録する場合は、著作権の扱いを安全衛生技術試験協会に確認してください。
- 有料配布する場合は、専門家（社労士・労働衛生コンサルタント等）による監修を受けると安心です。
